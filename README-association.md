# نسخة جمعية مساجد من الموقع الأصلي

تم الحفاظ على واجهة الموقع الأصلية وأدوات الخريطة والبحث والتجميع والوضع الليلي والإحصائيات والتصدير. مصدر البيانات الوحيد هو association-mosques.xlsx، ويقرأ أول ورقة عمل مباشرة.

## تحديث البيانات
استبدل association-mosques.xlsx بملف الجمعية المحدّث بالاسم نفسه. عناوين الصف الأول: رقم المسجد، اسم المسجد، الحي، حالة الإنجاز، الأعمال المنجزة، خط الطول، خط العرض. رقم المسجد مطلوب وفريد، واسم المسجد مطلوب. القيم الحالية لحالة الإنجاز: لم يبدأ، تم الإنجاز. تفاصيل المسجد تعرض البيانات الفعلية فقط. التصنيف مسجد/جامع مشتق من بدء الاسم بكلمة «جامع».

## التشغيل والتسليم
شغّل الموقع عبر استضافة ثابتة أو python3 -m http.server 8080 ثم افتح http://localhost:8080 . يلزم الاتصال بالإنترنت للمكتبات والخريطة.

ملفات التسليم فقط:
- index.html
- script.js
- style.css
- association-mosques.xlsx
- association-logo.jpg
- README-association.md

لا تُسلّم ملفات CSV وJSON والصور والعروض القديمة أو مجلد masajed؛ لا يقرأها الموقع المعدل. احتُفظ بها محليًا لحماية الأصل. إعدادات الخريطة ومفتاح CARTO الموجود في الكود الأصلي بقيت كما هي؛ استخدم مفتاح الجمعية عند التسليم.
